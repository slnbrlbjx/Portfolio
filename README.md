# Mon Portfolio

Portfolio personnel hébergé sur GitHub Pages avec un thème violet.

## Structure

- `index.html` - Page d'accueil (profil & parcours)
- `formations.html` - Formations et certifications
- `qualifications.html` - Compétences et centres d'intérêt
- `projets.html` - Projets
- `css/style.css` - Feuille de style (thème violet)

## Déploiement

Ce site est automatiquement déployé sur GitHub Pages à l'adresse :
`https://[username].github.io/Portfolio/`

## Personnalisation

Modifiez les fichiers HTML pour ajouter votre contenu et personnalisez les couleurs dans `css/style.css` via les variables CSS.
